# EXP-008：MSE 回归损失

## 实验目的

验证 MSE 对大误差的二次惩罚能否减轻正负情感预测向 0 收缩的问题。

## 对照设计

- 对照组：Text-BiGRU + Smooth L1（beta=0.5）。
- 实验组：Text-BiGRU + MSE。
- 唯一变量：回归损失；分类权重恢复为 `power=1.0`，其余设置不变。
- 筛选阶段使用 seed=2026，仅查看验证集。

## 运行命令

```powershell
python train_baselines.py --models text_bigru --run-name exp008_regression_mse --regression-loss mse --epochs 50 --patience 8 --batch-size 64 --validation-only
```

## 验证集结果

| 回归损失 | Macro-F1 ↑ | MAE ↓ | Pearson ↑ | Selection score ↑ |
|---|---:|---:|---:|---:|
| Smooth L1 | **0.6351** | **0.5753** | **0.6629** | **1.1063** |
| MSE | 0.6051 | 0.5853 | 0.6532 | 1.0633 |

原始产物：`outputs/exp008_regression_mse/`

## 结果分析与结论

- MSE 未降低 MAE，也未提高 Pearson，同时 Macro-F1 明显下降。
- 更强的大误差惩罚没有解决预测向 0 收缩，反而可能让共享表示为回归任务让步，损害分类。
- 保留 Smooth L1。至此停止当天的连续模型调参，防止对单一验证集过拟合；下一阶段先研究困难样本、标签边界和题目要求的可解释专项数据。
