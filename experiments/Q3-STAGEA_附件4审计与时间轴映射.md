# Q3-STAGEA：附件4审计与原始时间轴映射

## 实验目的

在进行问题3解释算法前，先回答三个基础问题：附件4两套特征是否一一对应；模型的50个位置如何回落到原视频秒数；哪些样本不能输出强解释。

## 数据与方法

- 数据：附件4对齐版20个pickle、未对齐版20个pickle及两套同名视频。
- 审计：字段、形状、数值有限性、视频哈希、帧率、时长和有效长度。
- 文本时间轴：官方文本按词切分，用`torchaudio.pipelines.MMS_FA`对原音轨强制对齐；BERT WordPiece再通过字符区间指向对应词。
- 未对齐时间轴：音频按20 Hz、视觉按15 Hz恢复到以音轨起点为0秒的物理时间。
- 独立复核：MMS样本均值低于0.6时，仅用Whisper复核时间映射可靠性，不替换官方文本、不生成伪标签。

## 关键结果

1. 对齐版、未对齐版和视频均为20条，编号01—20完全配对；两套视频20/20逐字节一致。
2. 两版`raw_text`、`id`、`text`和`text_bert`均20/20一致。本地BERT重新编码的`text_bert`也与附件4 20/20完全一致。
3. 共479个官方文本词，50-token接口覆盖457个。07号截断15词，18号截断7词；完整词级时间表仍保留，但截断词不能声称影响模型预测。
4. MMS样本平均分的均值为0.8498。15号均值0.4164，Whisper复核WER=1.3529，官方文本与实际音轨并非同一完整片段，因此15号禁用逐词精确秒数解释。
5. `vision_lengths`在13、16号错误记录为1，但后续分别仍存在非零特征；已按最后非零位置恢复有效范围。13号的对齐视觉50位置仍全零，因此正式模型不能把13号解释为视觉参与。
6. 16/20条视频流与音轨时长差超过0.1秒，最大差7.8901秒。不能把50位置或未对齐特征按视频流总时长线性拉伸；解释统一以音轨0秒为共同原点。

## 质量分层

| 类型 | 样本数/编号 | 后续处理 |
|---|---|---|
| 词级时间映射高可靠 | 15条 | 可输出词及秒级区间，同时保留对齐分数 |
| 词级时间映射中可靠 | 4条 | 可输出，但标注中等可靠 |
| 禁止逐词精确定位 | 15号 | 文本重要性与粗粒度音视频证据分开报告 |
| 50-token文本截断 | 07、18号 | 只解释实际进入模型的前50个BERT位置 |
| 正式模型视觉证据不可用 | 13号 | 视觉贡献记为不可用/零，不强行指定关键帧 |
| 视觉长度元数据异常且已纠错 | 13、16号 | 使用非零范围重建时间索引，不信任原`vision_lengths=1` |

## 对下一阶段的约束

- 阶段B必须读取`evidence_policy.csv`，不能对所有样本套用同一种解释模板。
- token遮挡/梯度解释只在`attention_mask=1`且有`word_index`的位置上执行。
- 音频和视觉局部证据可以按未对齐固定帧率定位；13号不得宣称视觉改变正式模型输出。
- 解释算法不得利用附件4预测反向调阈值，因为附件4无标签。
