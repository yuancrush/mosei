# EXP-006：Text-BiGRU 跨种子验证集错误分析

## 实验目的

在继续修改结构前，定位候选模型稳定存在的分类与回归误差，确保下一次改动由证据驱动。

## 分析设计

- 汇总 seed=2026、2027、2028 的验证集预测。
- 计算每一类的 Precision、Recall、F1，以及按真实类别划分的回归 MAE 和有符号偏差。
- 保留三个种子共同错分的困难样本清单。

## 运行命令

```powershell
python analyze_validation_errors.py
```

## 结果

| 类别 | Precision | Recall | F1 | 回归 MAE | 回归偏差（预测-真实） |
|---|---:|---:|---:|---:|---:|
| Negative | 0.6797 | 0.6861 | 0.6825 | 0.7541 | +0.5228 |
| Neutral | **0.4469** | 0.6069 | **0.5139** | 0.3353 | +0.1147 |
| Positive | 0.7682 | 0.6124 | 0.6812 | 0.6096 | -0.4309 |

- 728 个验证样本中，有 215 个被三个种子共同错分。
- 原始产物：`outputs/exp006_error_analysis/`。

## 结果分析与引导意义

- Neutral 的 Precision 显著低于 Recall，模型过度预测中性；当前完全逆频率权重可能对样本最少的 Neutral 补偿过强。
- 正负类回归均明显向 0 收缩，是 MAE 的主要来源；这与情感极性样本更难拟合、Smooth L1 倾向保守预测一致。
- 下一步先把类别权重由完全逆频率改为平方根逆频率，只改变权重强度，观察 Neutral 精确率和 Macro-F1 是否改善。
