# EXP-009 附件3缺失审计与压力测试

## 实验目的

先识别附件3的真实缺失结构，再建立与赛题一致的验证集压力测试，回答缺失模态类型、位置和持续比例如何影响性能。该实验不训练新模型。

## 数据审计

- 30/30 个样本文本均完整，30/30 个样本音频和视觉存在零值时间步。
- 音频与视觉的平均零值比例分别为 29.60% 和 29.99%；官方验证集自然零值比例分别为 10.26% 和 15.59%，附件3的超额比例约为 19.34% 和 14.40%。
- 29/30 个样本的音频、视觉零值位置完全相同，说明主要场景是联合局部缺失；另1个样本视觉缺失更多。
- 音频零值比例的范围为 12.12%～53.85%，中位数为 26.49%。零值中包含首尾对齐空位等自然结构，不能把所有零值都解释为人工缺失。

可复现命令：

```powershell
python audit_missingness.py
```

原始结果：`reports/attachment3_audit/summary.json`、`samples.csv`、`intervals.csv` 和 `missing_ratio.png`。

## 压力测试设计

- 数据：官方 validation，避免用 test 指导设计。
- 模态类型：仅音频、仅视觉、音频+视觉联合缺失。
- 持续比例：10%、30%、50%。
- 位置：前段、中段、后段。
- 对照模型：普通三模态均值池化、Text-BiGRU、Text+Audio-BiGRU。
- 每个块按文本有效长度定位，原有自然无效步仍保持无效。

```powershell
python evaluate_missingness.py
```

## 关键结果

| 模型 | 场景 | Macro-F1 | MAE | Pearson |
|---|---|---:|---:|---:|
| 普通三模态 | 完整 | 0.6015 | 0.6199 | 0.6108 |
| 普通三模态 | 联合中段30% | 0.5960 | 0.6193 | 0.6136 |
| 普通三模态 | 联合中段50% | 0.5916 | 0.6178 | 0.6154 |
| Text-BiGRU | 所有音视频缺失场景 | 0.6351 | 0.5753 | 0.6629 |
| Text+Audio-BiGRU | 完整 | 0.6132 | 0.5699 | 0.6701 |
| Text+Audio-BiGRU | 音频中段50% | 0.6036 | 0.5708 | 0.6737 |

注：修正 BiGRU 的内部缺口截断问题后，Text+Audio-BiGRU 的完整场景复算值与旧记录略有差异；新结果采用正确的“最后有效位置”作为序列范围。

## 分析与引导意义

1. 附件3与“文本完整、音视频联合局部缺失”高度一致，后续主实验不应平均分配到所有缺失组合。
2. 现有三模态模型对遮挡的额外退化不大，但其完整数据性能已显著低于文本模型；首要矛盾是弱模态负迁移，而非缺失后的灾难性崩溃。
3. 位置效应小于模型间差异，暂不值得为前/中/后位置分别设计网络。
4. Text+Audio 的回归优势在遮挡下基本保留，而分类仍弱于 Text-BiGRU；分类和回归可考虑采用不同的专家输出。
5. 下一实验应先做来源/判别不确定性加权；只有在轻量融合仍不足且补全目标可验证时，才考虑扩散生成。
