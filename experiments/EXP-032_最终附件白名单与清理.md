# EXP-032 最终附件白名单与清理

## 目的

将三个问题的正式产物合并为唯一提交附件，执行样本数、权重数、禁用项、大小和SHA256校验，并清除容易误交的旧预测、冒烟输出及淘汰权重。

## 白名单内容

- 问题1：100条三模态NPZ、全量汇总、质量审计、人工ASR复核和典型图。
- 问题2：附件3正式30条预测、3个分类权重、3个回归权重，以及连续缺失、不确定性、门控和训练轨迹证据。
- 问题3：附件4正式20条预测、模态贡献、局部证据、时间映射和18张有效关键帧。
- 复现：核心`src/mosei`代码、必要脚本和`environment-mosei.yml`。
- 写作依据：最终实验记录和最新增量交接。

## 已清理内容

- EXP-016旧Text-BiGRU附件3预测目录；正式结果唯一保留EXP-020C版本。
- 5个名称含`_smoke`的冒烟目录。
- EXP-019已淘汰的54.48MB BERT微调权重；保留指标、日志和失败结论。
- 已被统一附件吸收的旧问题1独立ZIP及其旧摘要。

所有删除项均有Git历史，必要时可恢复，但不得用于正式提交。

## 校验结果

- ZIP：`submission/研究生数学建模E题_最终提交附件.zip`
- 样本数：问题1=100，附件3=30，附件4=20。
- 冻结权重：分类3个、回归3个。
- 禁止项：无smoke、无EXP-016旧预测、无淘汰BERT权重、无原始赛事数据。
- 体积与SHA256以`submission/package_summary.json`为准。

## 复现

```powershell
conda activate mosei
python build_final_submission.py
```

脚本按显式白名单重新打包，任何必需文件缺失、样本数不符、出现禁用路径或超过50MB都会直接报错。
