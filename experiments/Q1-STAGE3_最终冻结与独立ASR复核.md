# Q1-STAGE3：最终冻结与独立ASR复核

## 实验目的

消除问题1的三个残留歧义：BERT padding接口是否与附件2一致、视频总时长是否被误写成模态有效时长，以及22条低MMS对齐置信度样本是否真的能够支持词级物理时间定位。

## 修改与验证

1. 100条固定层文本恢复BERT原始padding隐状态，下游继续由`text_bert[1]`排除padding。
2. 每条NPZ和汇总表分别保存视频、文本、音频、视觉有效时长。
3. 使用通用预训练`openai/whisper-base.en`独立复核22条低MMS分样本；该模型只做质量审计，不参与情感训练或标签生成。
4. 重新运行结构检查、18条重合样本接口验证和提交包生成。

## 结果

| 检查项 | 结果 |
|---|---:|
| NPZ结构/有限值/区间合法 | 100/100通过 |
| 存在padding的样本 | 93 |
| padding均保留BERT原始输出 | 93/93通过 |
| 完整50位置BERT RMSE | 6.22×10⁻⁷ |
| MMS自动高置信 | 78 |
| 低MMS分且获独立ASR支持 | 2 |
| 低可靠时间映射 | 20 |
| 最终可用时间映射 | 80 |
| 提交包 | 21.14 MB，低于50 MB |

## 分析与写作意义

独立ASR揭示了此前只看“区间有序、形状正确”无法发现的问题：20条官方转写与视频音轨识别内容差异较大。它们不能被写成精确对齐成功，也不应删除或私自改写官方文本。最终方案保留全部特征和候选区间，同时增加可靠性字段；在问题3证据定位时回避低可靠词级时间戳或明确降级为视频整体证据。

因此问题1的正确结论是“100条工程产物完整，80条词级时间映射可用，20条映射低可靠”，而不是“只有80条成功”或“100条全部精确对齐”。
