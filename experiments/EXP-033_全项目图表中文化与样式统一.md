# EXP-033 全项目图表中文化与样式统一

## 目的

消除历史实验图中英文标题、英文模态名、隐式英文轴标签及字号不一致问题，使问题1—3与补充实验的图表可以直接进入中文论文。

## 执行方式

- 修改各 Python 绘图函数并重新运行，未对 PNG 做像素级或生成式编辑。
- 从现有 `history.json`、预测记录、统计 CSV 和已冻结结果重绘。
- 问题1图从原视频和既有特征重新渲染。
- 未重新训练，未重新执行官方 test；`RUN_COMPLETE.json` 保持不变。

## 结果

- 项目内60张 PNG 全部由代码重新生成并覆盖。
- 重绘包含34张训练曲线、5张混淆矩阵、5张历史缺失压力图、5张定型诊断图、2张问题1提交图，以及问题1质量图、附件3审计图和问题3写作用图。
- 全部图题、坐标语义、图例对象、模态名和类别名已中文化。
- `Accuracy`、`Macro-F1`、`MAE`、`Pearson` 等标准指标保留英文；`BERT`、`BiGRU`、`L2` 等标准缩写保留。
- 混淆矩阵的隐式 `True label / Predicted label` 已显式替换为“真实类别 / 预测类别”。
- 对颜色、线型、阈值或多曲线有实际含义的图补齐图例；例如连续缺失鲁棒性三联图的三个子图现均含完整“缺失情形”图例。类别已由坐标直接标明的混淆矩阵、带色条的热力图等不重复堆叠无效图例。

## 复现与审计

- 重绘入口：`redraw_all_figures_chinese.py`
- 样式入口：`plot_style.py`
- 图表清单：`reports/figure_audit/全项目图表清单.csv`
- 术语规范：`reports/figure_audit/术语与样式规范.md`

本实验只改变呈现，不改变任何模型、预测或评价指标数值。
