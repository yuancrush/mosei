# E题最终提交附件说明

本目录只保留唯一正式附件压缩包、内容清单和校验信息。论文文档由赛事系统单独提交，不放入本附件。

## 压缩包目录

- `01_问题1特征与对齐`：100条原始视频的三模态特征、全量汇总、质量审计和典型图。
- `02_问题2预测与模型`：附件3正式预测、冻结模型权重、连续缺失、不确定性和门控响应证据。
- `03_问题3预测与解释`：附件4正式预测、模态贡献、局部证据、时间映射和视觉关键帧。
- `04_复现源码`：必要脚本、核心模型代码和conda环境文件。
- `05_实验说明`：最终模型及补充实验的中文记录。

## 数据目录约定

原始赛事数据不进入压缩包。复现时将赛事附件保持原目录结构放在`pythonproject`同级的`E题数据`目录；程序会自动搜索`aligned_50.pkl`。附件3、附件4均无标签，只允许冻结推理，不得伪标签回灌。

## 固定口径

- 三分类编码：0=负向、1=中性、2=正向；连续值0只属于中性。
- 问题2是连续时间段局部缺失，不是整模态缺失。
- 附件3、附件4无标签，预测表中的一致率和标准差是不确定性指标，不是准确率。
- 官方test已经在模型冻结后唯一评估一次，附件内脚本不得据此重新调参。

## 校验

提交前核对`package_summary.json`中的文件数、样本数、ZIP大小和SHA256；逐文件清单见`最终附件_内容清单.csv`。
