# 第1天实验阶段总结

## 1. 今天回答的核心问题

1. 数据划分、mask、标准化和训练流程是否可靠？——已通过审计和复验。
2. 哪个模态是主信号？——文本显著强于音频与视觉。
3. 时序建模是否有价值？——Text-BiGRU 在三随机种子上稳定提高 Macro-F1 和 Pearson。
4. 弱模态能否直接改善文本模型？——音频只带来小幅回归增益并损害分类，视觉全面退化，门控也未超过纯文本。
5. 简单正则化或损失替换能否继续提高？——dropout=0.5、平方根类别权重、MSE 均失败。

## 3. 稳健性结论

三随机种子下，Text-BiGRU 相对 Text-Mean：

- Macro-F1：0.6259 ± 0.0082 对 0.6035 ± 0.0019，3/3 种子提高。
- Pearson：0.6633 ± 0.0100 对 0.6351 ± 0.0117，3/3 种子提高。
- MAE：0.5811 ± 0.0147 对 0.6017 ± 0.0097，平均改善，但只在 2/3 种子改善。

因此可以把“时序建模有效”作为阶段结论，但不能声称回归误差在每个随机种子上都稳定下降。

## 4. 错误结构

- Neutral：Precision 0.4469、Recall 0.6069，存在明显过预测。
- Negative 回归平均偏差 +0.5228，Positive 平均偏差 -0.4309，预测向中性区域收缩。
- 728 个验证样本中，215 个被三个种子共同错分，应作为后续定性分析的重点样本池。

## 5. 当前冻结方案

- 主模型：Text-BiGRU + 注意力池化。
- hidden=128，dropout=0.3。
- 完全逆频率类别权重。
- Smooth L1 回归损失，分类与回归权重 1:1。
- 迭代阶段继续禁止查看测试集。

## 6. 下一阶段建议

1. 结合原始样本与可解释专项附件，检查稳定困难样本是否集中于反讽、否定、情感转折、标签边界或截断序列。
2. 分析序列长度与错误率，验证 50 步截断和短序列是否影响结果。
3. 在有明确证据后再选择一个方向：标签边界建模、困难样本重加权，或任务解耦；不要继续无目标调超参数。
4. 候选方案冻结后再统一运行测试集，并把测试集只使用一次写入论文实验协议。
