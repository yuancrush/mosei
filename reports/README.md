# 报告与写作材料索引

本目录同时保存阶段报告、实验审计和论文写作材料。为避免把历史结论误当成当前结论，请按下面顺序阅读。

## 1. 写作人员的唯一入口

1. 先读 [`writing_handoffs/README.md`](writing_handoffs/README.md)，确认各问题当前是否已经冻结，以及是否存在增量纠偏。
2. 问题1的基础材料仍为 [`问题1完整求解与写作材料.md`](问题1完整求解与写作材料.md)。
3. 问题1涉及“80条可用、20条低可靠”的旧口径时，先读 [`writing_handoffs/Q1_2026-09-24_人工复核增量交接.md`](writing_handoffs/Q1_2026-09-24_人工复核增量交接.md)，再读最新的 [`writing_handoffs/Q1_2026-09-25_典型图重构与文档纠偏交接.md`](writing_handoffs/Q1_2026-09-25_典型图重构与文档纠偏交接.md)，以最新文件为准。
4. 问题2已冻结，正式数字见[`writing_handoffs/Q2_2026-09-24_局部缺失与三模态预测交接.md`](writing_handoffs/Q2_2026-09-24_局部缺失与三模态预测交接.md)。
5. 问题3已冻结，正式写作口径见[`writing_handoffs/Q3_2026-09-24_可解释性预测交接.md`](writing_handoffs/Q3_2026-09-24_可解释性预测交接.md)。阶段过程分别见[`第3问阶段A_数据审计与时间轴映射.md`](第3问阶段A_数据审计与时间轴映射.md)、[`第3问阶段B_解释方法与验证结果.md`](第3问阶段B_解释方法与验证结果.md)和[`第3问阶段C_附件4正式解释与交付.md`](第3问阶段C_附件4正式解释与交付.md)。

## 2. 文件用途

| 文件或目录 | 用途 | 能否直接作为论文结论 |
|---|---|---|
| `writing_handoffs/` | 按时间追加的写作交接与纠偏 | 可以，按最新版本优先 |
| `问题1完整求解与写作材料.md` | 问题1基础方法、公式、表格和边界 | 可以，但冲突数字以增量交接为准 |
| `question1_stage_a/` | 对齐复核原始证据及统计 | 用于核验，不直接照抄 |
| `第2天24小时实验总计划.md` | 实验排程与止损条件 | 不可以，它是计划，不是结果 |
| `第2天阶段B实验总结.md` | 阶段B已完成实验摘要 | 可用于过程叙述，不能冒充最终模型 |
| `问题2三模态升级实验方案与执行结果.md` | 阶段C候选结构、执行顺序与止损线 | 只用于实验设计；结果以EXP-020系列记录为准 |
| `第1天*.md`、`当前解题进度与剩余阶段.md` | 历史进度快照 | 不可以作为最新结论 |
| `baseline_report.md` | 最小基线结果 | 只用于基线对比 |
| `data_audit.json`、各审计子目录 | 可复核数据证据 | 可以作为表格数据源 |
| `question3_stage_a/` | 附件4审计、证据降级策略和中文质量图 | 可写数据与时间轴；不能冒充解释实验结果 |

## 3. 增量交接规则

- 已发给写作人员的交接不直接重写。
- 新发现只新增带日期的交接文件，并在 `writing_handoffs/README.md` 登记覆盖关系。
- 新交接必须写清：改变了什么、未改变什么、需要修改论文哪几处、哪些旧表述停用。
- 问题2和问题3沿用同一规则。模型未冻结前，只能写方法框架和实验协议，不能预填最终指标。
