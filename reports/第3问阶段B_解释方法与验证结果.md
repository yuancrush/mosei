# 第3问阶段B：解释方法与验证结果

## 已完成内容

问题3解释方法已在附件2官方验证集上完成选择，没有使用附件4调参。正式方法由模态反事实消融、连续时间块遮挡和三随机种子稳定性共同构成。

## 最终协议

| 输出 | 方法 | 正式粒度 |
|---|---|---|
| 情感极性主要证据 | 预测类别概率的反事实下降 | 连续5位置块，Top-2 |
| 情感强度主要证据 | 回归值反事实变化绝对值 | 连续10位置块，Top-1 |
| 模态作用程度 | 整个模态移除后的绝对变化归一化 | 文本/音频/视觉分别计算 |
| 作用方向 | 原预测减去模态移除后的预测 | 正值为支持当前输出，负值为抑制/纠偏 |
| 解释可靠性 | 三种子Top位置一致性、分类投票一致率、回归标准差 | 分开报告 |

## 可信度证据

- 分类5位置块：Top删除概率下降0.1876，随机删除0.0146，96.02%的样本Top影响更大；只保留Top证据比随机保留高0.3194。
- 回归10位置块：Top删除强度变化0.2617，随机删除0.1162，79.12%的样本Top影响更大。
- 三种子Top-1一致率：分类0.7024，回归0.6241。
- 配对bootstrap的95%置信区间均不跨0，Wilcoxon单侧检验均显著。

## 写作边界

1. 文本是分类主证据，不得称三种模态“贡献相当”。
2. 音频和视觉有实际小幅纠错作用，可以报告大小和方向，但不能用注意力权重夸大。
3. 回归证据只能按较粗的10位置块解释，不能伪装成单词级强度因果定位。
4. 附件4无标签，正式解释只是冻结模型输出，不能宣称其预测正确率。
