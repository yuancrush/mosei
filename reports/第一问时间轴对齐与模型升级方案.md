# 第一问时间轴对齐与模型升级方案

## 当前判断

第一问要求从附件1原始视频完成文本、音频、视觉特征提取和时间对齐，并提交100个样本的特征文件与可追溯日志。当前工程主要使用附件2的预提取特征开展问题2和问题3建模，因此只完成了对齐结构的反向验证，尚未完成附件1的原始特征提取交付。

## 时间轴定义

对每个视频片段定义物理时间轴 `t∈[0,D]`，其中 `D` 为视频时长。转写文本经强制对齐后得到词级区间 `I_j=[s_j,e_j)`。音频和视觉先在各自原生采样频率上提取帧级特征，再映射到词区间。

对第 `j` 个词区间，定义：

```text
a_j = mean{a(t): t∈I_j}
v_j = mean{v(t): t∈I_j}
```

其中 `a(t)`、`v(t)` 分别为音频帧和视觉帧特征。没有有效帧时置零并记录缺失掩码，而不是用全局均值填充。

## 50位置对齐轴

附件2的 `aligned_50.pkl` 采用文本锚定的离散序列轴：

- `text: (N,50,768)`：BERT最后一层token表示。
- `audio: (N,50,74)`：映射到同一token或词区间的声学特征。
- `vision: (N,50,35)`：映射到同一区间的视觉特征。
- `text_bert: (N,3,50)`：token id、attention mask、token type id。
- 50是最大存储长度，不是50个等长物理时间片；有效长度由attention mask给出。
- `[CLS]`、`[SEP]`和padding位置的非文本模态为零。
- 一个词被拆成多个WordPiece时，各子词继承同一词区间的音频和视觉聚合特征；数据中可观察到连续相同的非文本向量。

因此，第 `i` 个离散位置的三模态表示为：

```text
x_i = (x_i^T, x_i^A, x_i^V),  i=1,...,L,  L≤50
```

它表示“同一词义时间区间”，而不是同一固定毫秒窗口。

## 当前预测模型

每个模态先经过 `LayerNorm → Linear(128) → GELU → Dropout(0.3)`，再进入双向GRU。前向和后向隐藏维各64，输出维128。掩码注意力池化为：

```text
e_i = wᵀh_i+b
α_i = softmax(e_i; mask)
z = Σ_i α_i h_i
```

当前最终采用任务专家集成：

- 分类：三个 Text-BiGRU 多数投票。
- 回归：三个 Text+Audio-BiGRU 预测均值。
- 分类损失：完全逆频率加权交叉熵。
- 回归损失：Smooth L1，`beta=0.5`。
- 优化器：AdamW，学习率 `1e-3`，权重衰减 `1e-4`。

验证集 Macro-F1/MAE/Pearson 为 `0.6343/0.5648/0.6772`。

## 更高性能模型的优先级

### 优先级1：部分微调BERT

当前768维文本特征完全冻结，BiGRU只能在固定表示上学习。优先实验应直接读取 `text_bert`，冻结BERT底部10层，只微调顶部2层：BERT参数学习率 `2e-5`，任务头学习率 `1e-3`，batch size 16，最多8至12轮。该实验只使用附件2标签。

### 优先级2：MAG式文本锚定残差

在每个token位置将音频投影作为受掩码门控的残差注入BERT：

```text
g_i^A = sigmoid(W_g[h_i^T; P_A x_i^A; m_i^A])
h'_i = LayerNorm(h_i^T + g_i^A ⊙ P_A x_i^A)
```

视觉先作为消融分支，不默认进入主模型。该结构比直接拼接更符合现有实验中“文本强、音频主要改善回归、视觉易负迁移”的证据。

### 优先级3：任务解耦的联合训练

共享BERT主干，但分类头仅使用文本表示，回归头使用文本加音频门控表示；避免分类和回归争夺同一个融合空间。训练目标为：

```text
L = L_cls(text) + λ L_reg(text,audio) + γ L_consistency
```

### 暂不优先

- 完整MulT或三路交叉Transformer：参数量和路径较多，当前3395个训练样本下过拟合风险高。
- Tensor Fusion：维度膨胀且不直接解决弱模态负迁移。
- 完整扩散或生成补全：附件3文本完整，现阶段投入产出比低。
