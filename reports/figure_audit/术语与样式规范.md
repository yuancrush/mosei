# 科研图表术语与样式规范

## 适用范围

本规范适用于 `outputs/` 与 `reports/` 中由 Python 生成的全部科研图。原始视频关键帧、英文转写词和样本编号属于原始证据，不作翻译或改写。

## 语言口径

- 图题、坐标含义、图例对象、类别名和模态名使用中文。
- 标准评价指标保留英文缩写：`Accuracy`、`Macro-F1`、`MAE`、`Pearson`。
- 标准模型与数学缩写保留原写法：`BERT`、`BiGRU`、`GRU`、`L2`。
- 三模态统一写作“文本、语音、视觉”，不混用“音频/Audio”和“图像/Vision”。
- 三分类统一写作“负向、中性、正向”，其中标签0只属于中性。
- `Top证据`统一写作“最高贡献证据”或“首要证据”。

## 字体与字号

- 首选字体：微软雅黑；备选为黑体、思源黑体和 DejaVu Sans。
- 图总标题：14 pt；子图标题：12 pt；坐标轴标题：10.5 pt。
- 刻度与图例：9.5 pt；正文默认：10.5 pt。
- 负号使用 Unicode 正常显示；保存时采用紧边界，默认分辨率为200 dpi。

统一样式由项目根目录的 `plot_style.py` 提供。完整重绘命令为：

```powershell
conda activate mosei
python redraw_all_figures_chinese.py
```

该命令只读取已有结果、日志和问题1原始视频来绘图，不重新训练，也不重新运行官方 test。
